Dashboard Management Data Pegawai v2.0

Sistem Pengelolaan & Visualisasi Data Pegawai Terintegrasi Google Spreadsheet

Fitur Utama Sistem

  • Live Google Spreadsheet Integration: Sinkronisasi data otomatis langsung dari cloud spreadsheet.
  • Fallback & Local Offline Support: Dukungan import file manual Excel (`.xlsx`) / CSV jika protokol lokal `file://` dibatasi browser.
  • Perhitungan Pensiun Otomatis: Estimasi waktu hitung mundur sisa masa bakti pegawai berdasarkan BUP.
  • Dark & Light Mode: Dukungan tampilan mode gelap dan terang demi kenyamanan penglihatan.
  • Filter & Multi-Export: Menyaring data dinamis dan ekspor ke Excel siap cetak.

Cara Mempublikasikan Google Sheet

  1. Buka spreadsheet Google Anda.
  2. Pilih menu File → Bagikan (Share) → Publikasikan ke web.
  3. Ubah opsi ke All Pegawai dan pilih format Nilai yang dipisahkan koma (.csv).
  4. Klik Publikasikan dan salin link publik tersebut.
  5. Buka menu Ganti Link pada dashboard ini dan simpan URL-nya.
